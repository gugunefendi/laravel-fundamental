aplikasi web modern seperti routing, validation, caching, queues, file storage dan masih banyak lagi. 


*** Bisakah membangun Front End di Laravel 12 ***
Bisa.
Meskipun Laravel adalah framework backend yang sudah menyediakan banyak untuk bangun aplikasi modern.
Namun Laravel juga menyediakan fitur untuk kita (Full Stack Developer) untuk membangun front end di aplikasi Laravel kita.


*** Dengan apa aja bisa membangun Front End di Laravel 12 ***
Ada dua cara untuk membangun front end di Laravel:
1. PHP
  Untuk membangun front end dengan PHP ada dua cara:
    - Blade
    - Livewire
2. Javascript
  - Vue
  - React
  Catatan* dalam tutorial ini kita akan menggunakan Inertia, Inertia akan menjadi jembatan antara Laravel dengan React / Vue.

Untuk memudahkan kita dalam belajar front end di Laravel, kita akan membuat mini project.
Kita buat migrasi dulu, caranya:
1. Buat sebuah migrasi untuk table products
    Ketikkan di terminal php artisan make:migration create_products_table
    Lalu isi file migration tersebut dengan beberapa field
    $table->string('name');
    $table->integer('price');
    $table->integer('stock');

2. Setelah itu kita buat sebuah model
    Ketikkan di terminal php artisan make:model Product
    Lalu kita buat sebuah properti
    protected $table = 'products';
    protected $fillable = ['name', 'price', 'stock'];

3. Selanjutnya kita migrate table-nya
    Caranya ketikkan di terminal php artisan migrate

4. Lalu kita buat sebuah ProductController caranya ketik di terminal
    php artisan make:controller ProductController

Oke sekarang kita udah punya table dengan nama products dan model dengan nama Product.

Sekarang kita bangun front end kita menggunakan Blade.
1. Membangun front end dengan Blade
    1.1  Buat file blade
          Buat sebuah folder dengan nama products didalam folder resources/views.
          Lalu buat sebuah file dengan nama list.blade.php.
          Sekarang ketikkan kode berikut
          <html>
          <head>
          	<style>
          		table, thead, tbody, th, tr, td {
          			border: 1px solid #cccccc;
          			margin-bottom: 20px;
          		}
          	</style>
          </head>
          <body>
          	<div>
          		<table>
          			<thead>
          				<th>Name</th>
          				<th>Price</th>
          				<th>Stock</th>
          			</thead>
          			<tbody>
          				@if(count($products) > 0)
          					@foreach($products as $prod)
          					<tr>
          						<td>{{ $prod->name }}</td>
          						<td>{{ $prod->price }}</td>
          						<td>{{ $prod->stock }}</td>
          					</tr>
          					@endforeach
          				@else
          					<span>No products found</span>
          				@endif
          			</tbody>
          		</table>
          		<form action="/product-store" method="post">
          		@csrf
          			<div>
          				<label>Product Name</label>
          				<input type="text" name="name" />
          			</div>
          			<div>
          				<label>Product Price</label>
          				<input type="number" name="price" />
          			</div>
          			<div>
          				<label>Product Stock</label>
          				<input type="number" name="stock" />
          			</div>
          			<button type="submit">Save</button>
          		</form>
          	</div>
          </body>
          </html>

    1.2 Modifikasi file ProductController
        Buka file ProductController yang ada didalam folder App\Http\Controllers
        Lalu ketikkan kode berikut
        <?php
        
        namespace App\Http\Controllers;
        
        use Illuminate\Http\Request;
        use App\Models\Product;
        
        class ProductController extends Controller
        {
        	protected $products;
        	
        	public function __construct(Product $prod)
        	{
        		$this->products = $prod;
        	}
        	
            public function index()
        	{
        		$products = $this->products->get();
        		return view('products.list', ['products' => $products]);
        	}
        	
        	public function store(Request $req)
        	{
        		$this->products->create([
        			'name' => $req->name,
        			'price' => $req->price,
        			'stock' => $req->stock
        		]);
        		
        		return redirect()->back();
        	}
        }

    1.3   Buat routing
          Buka file web.php yang ada didalam folder routes.
          Lalu ubah kodenya menjadi seperti dibawah ini.
          <?php
          
          use Illuminate\Support\Facades\Route;
          use App\Http\Controllers\ProductController;
          
          Route::get('/', function () {
              return view('welcome');
          });
          
          Route::get('/products', [ProductController::class, 'index']);
          Route::post('/product-store', [ProductController::class, 'store']);

Oke sekarang jalanin project Laravel kita dengan ketik di terminal composer run dev lalu buka url http://localhost:8000/products.
Maka akan muncul sebuah halaman yang menampilkan table dari isi table products dan form untuk menambah product.

Sampai sini maka kita sudah selesai menampilkan data dan membuat form untuk menambah data products dengan Blade.

2. Membangun Front End dengan Livewire
    2.1 Install Livewire
        Buka terminal lalu ketikkan:
        composer require livewire/livewire
    2.2 Publish Configurasi
        Ketikkan di terminal
        php artisan livewire:publish --config
    2.3 Buat Componen ProductList
        Ketikkan di terminal 
        php artisan make:livewire ProductList
        Sekarang kita memiliki 2 file baru
        app/Http/Livewire/ProductList.php dan
        resources/views/livewire/product-list.blade.php
    2.4 Buat method di componen ProductList
        Ubah kode pada class ProductList menjadi seperti dibawah
        <?php

        namespace App\Livewire;
                
        use Livewire\Component;
        use App\Models\Product;
        use Livewire\Attributes\On;
                
        class ProductList extends Component
        {
            public $products = [];
                
            public function mount()
            {
                $this->loadProducts();
            }
             
            #[On('product-created')]
            public function loadProducts()
            {
                $this->products = Product::latest()->get();
            }
                
            public function render()
            {
                return view('livewire.product-list');
            }
        }


    2.5 Customize view live-wire di product-list
        Ubah kode pada view live-wire menjadi seperti dibawah
        <div>
            <table>
                <thead>
                    <tr>
                        <th>ID</th>
                        <th>Name</th>
                        <th>Price</th>
                        <th>Stock</th>
                    </tr>
                </thead>
                <tbody>
                    @foreach($products as $product)
                        <tr>
                            <td>{{ $product->id }}</td>
                            <td>{{ $product->name }}</td>
                            <td>{{ $product->price }}</td>
                            <td>{{ $product->stock }}</td>
                        </tr>
                    @endforeach
                </tbody>
            </table>
        
            <livewire:product-create />
        </div>

    2.6 Buat Componen Livewire dengan nama ProductCreate
        Caranya ketikkan perintah berikut di terminal
        php artisan make:livewire ProductCreate
        Maka kita akan dapat 2 file baru
        app/Livewire//ProductCreate.php
        resources/views/livewire/product-create.blade.php

    2.7 Customize Class ProductCreate
        <?php

        namespace App\Livewire;
        
        use Livewire\Component;
        use App\Models\Product;
        
        class ProductCreate extends Component
        {
            public $name = '';
            public $price = 0;
            public $stock = 0;
        
            public function save()
            {
                Product::create([
                    'name' => $this->name,
                    'price' => $this->price,
                    'stock' => $this->stock
                ]);
        
                $this->reset();
        
                $this->dispatch('product-created');
            }
        
            public function render()
            {
                return view('livewire.product-create');
            }
        }

    2.7 Customize view product-create
        <div>
            <form wire:submit="save">
                <div>
                    <label for="">Name</label>
                    <input type="text" wire:model="name">
                </div>
                <div>
                    <label for="">Price</label>
                    <input type="number" wire:model="price">
                </div>
                <div>
                    <label for="">Stock</label>
                    <input type="number" wire:model="stock">
                </div>
                
                <button type="submit">Save</button>
            </form>
        </div>


    2.8 Buat layout template
        Ketikkan di terminal 
        php artisan livewire:layout
        Ini akan menambahkan file app.blade.php di folder resources/views/components/layouts

    2.9 Buat Routing
        Tambahkan kode berikut pada routes/web.php menjadi:
        use App\Livewire\ProductList;
                
        Route::get('products', ProductList::class);

    3.0 Hasil
        Sekarang buka browser lalu buka url http://localhost:8000/products
        Kamu akan lihat view livewire kita yang bisa menyimpan data tanpa reload halaman penuh.
        Sampai tahap ini kita sudah berhasil belajar menggunakan Livewire.

Register middleware
php artisan inertia:middleware

use App\Http\Middleware\HandleInertiaRequests;

->withMiddleware(function (Middleware $middleware) {
    $middleware->web(append: [
        HandleInertiaRequests::class,
    ]);
})


Install dependency vue.js
npm install @inertiajs/vue3

Inisisalisasi Inertia resources/js/app.js
import { createApp, h } from 'vue'
import { createInertiaApp } from '@inertiajs/vue3'

createInertiaApp({
    resolve: name => {
        const pages = import.meta.glob('./Pages/**/*.vue', { eager: true })
        return pages[`./Pages/${name}.vue`]
    },
    setup({ el, App, props, plugin }) {
        createApp({ render: () => h(App, props) })
            .use(plugin)
            .mount(el)
    },
})

        return Inertia::render('ProductList');
